## Deployment
The repository-root `docker-compose.yml` is a local integration stack
(frontend on `localhost:3000`, API on `localhost:8080`). For the production
Caddy/TLS stack, CI publishing, and post-deployment checks, see
[nexuscore/DEPLOY.md](nexuscore/DEPLOY.md). A live deployment URL is pending
until a server and domain are configured and verified.
